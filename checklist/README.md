# 出发前准备清单

> 适用于 YGXL 马来西亚项目，4 人、2026/10/15 出发。入境规则和航司要求可能变化，出发前 7 天和出发前 24 小时各复核一次。

## 一、每位旅客单独准备

- [ ] 护照原件：确认普通护照有效期至少覆盖入境要求，并留有足够空白页
- [ ] 护照资料页电子备份：保存在手机离线相册或加密云盘，不上传 GitHub 或群聊公开位置
- [ ] 旅客代号对应关系：L、Y、G、X；公开项目只使用代号
- [ ] 往返机票信息：保存 AK113 和 AK116 的订单/值机信息
- [ ] 酒店信息：保存 Sunway Putra Hotel、Hatten Hotel Melaka 的地址和入住日期
- [ ] 旅行保险：保存保单号、紧急电话和理赔方式
- [ ] 常用药：按个人需要准备，并保留原包装；处方药同时准备处方或说明
- [ ] 个人支付备用方案：至少两种支付方式，并准备少量马来西亚现金

## 二、入境马来西亚

- [ ] 确认中国普通护照的免签/入境条件仍适用于本次旅游，并核对允许停留天数
- [ ] 在官方 MDAC 网站提交 Malaysia Digital Arrival Card；官方页面提示通常在抵达前 3 天内提交
- [ ] 保存 MDAC 提交成功页面或确认信息，必要时可离线出示
- [ ] 准备返程机票凭证、酒店订单和行程摘要，入境时可能需要说明
- [ ] 准备可用的支付方式和足够资金证明
- [ ] 不通过非官方代理或不明链接提交 MDAC；以马来西亚移民局官网为准

## 三、航班与亚航

- [ ] 在 AirAsia MOVE 或亚航官网确认 AK113 / AK116 状态
- [ ] 按航司要求完成在线值机，确认 4 人姓名、护照信息和座位
- [ ] 核对随身行李、托运行李额度和尺寸重量限制
- [ ] 下载或截图登机牌、订单号和航班信息
- [ ] 去程至少提前 3 小时到达广州白云 T3
- [ ] 返程目标在 13:00 前抵达 KUL T2，给托运、安检和出境留出余量

## 四、机场接机

- [x] 已确定：抵达 KUL T2 后，完成入境和取行李
- [x] 已确定：前往到达出口与 Trip.com 接机司机会合
- [x] 已确定：司机接到 4 人后，直接前往 Sunway Putra Hotel
- [ ] 出发前保存 Trip.com 接机订单凭证、司机联络方式和车辆信息
- [ ] 确认司机会合点是到达出口哪一侧、是否需要举姓名牌
- [ ] 准备酒店英文名和地址的离线截图
- [ ] 若司机未出现，先联系订单客服，不要自行取消订单后重新叫车

## 五、酒店入住

- [ ] 保存两家酒店的英文名称、地址和订单信息
- [ ] 准备 4 位旅客护照原件，以便前台登记
- [ ] 提前确认入住时间、押金/预授权、旅游税和可接受支付方式
- [ ] 确认房型、床型、早餐、Wi-Fi 和行李寄存规则
- [ ] 到店后核对房卡数量、入住人数和退房时间
- [ ] 保存前台电话；发现房间问题先拍照并及时反馈

## 六、网络、设备与文件

- [ ] 准备漫游、eSIM 或当地 SIM，并确认 4 人至少有一台手机可正常上网
- [ ] 下载离线地图，标记机场、酒店、接机点、KLCC、马六甲酒店和机场
- [ ] 手机、充电宝、转换插头和充电线全部充满并装入随身行李
- [ ] 将机票、酒店、接机、保险和 MDAC 信息放入同一离线文件夹
- [ ] 设置手机丢失后的远程锁定和支付账户保护

## 七、出发前最终复核

- [ ] 出发前 7 天：确认入境政策、MDAC、航班、酒店和接机
- [ ] 出发前 3 天：提交 MDAC，完成在线值机可做则完成
- [ ] 出发前 24 小时：查看天气、航班状态、接机消息和酒店通知
- [ ] 出发当天：护照、手机、钱包、登机牌、药品和充电宝放在随身包
