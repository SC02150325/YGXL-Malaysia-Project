# 出发前准备与确认清单

> 这是 YGXL 马来西亚项目最重要的执行清单。所有事项分为“个人确认”和“团队共同确认”两部分。个人事项由每位旅客自己负责，团队事项由 4 人共同讨论并指定负责人。
>
> 旅行时间：2026/10/15 - 2026/10/18 · 4 人 · 广州 → 吉隆坡 → 马六甲 → 吉隆坡机场 → 广州

## 使用规则

- 每位旅客先完成“个人确认”，不能只依赖其他人记住自己的信息。
- 团队事项需要明确结论、负责人和完成时间。
- `[x]` 表示已经确认；`[ ]` 表示待确认；有变化时同步更新 `CHANGELOG.md`。
- 入境和航司规则可能变化，出发前 7 天、3 天和 24 小时分别复核。

# 一、每位旅客个人确认

## 1. 证件与个人信息

- [ ] 身份证原件
- [ ] 护照原件，确认姓名、证件号码和有效期无误
- [ ] 记住自己的旅客代号：L、Y、G 或 X
- [ ] 知道自己的房间、床位或同行安排
- [ ] 准备个人常用药、处方药和必要的医疗用品

## 2. 自己必须掌握的航班信息

- [ ] 去程 AK113：10/15 广州 CAN T3 10:20 → 吉隆坡 KUL T2 14:40
- [ ] 返程 AK116：10/18 吉隆坡 KUL T2 16:35 → 广州 CAN T3 20:55
- [ ] 知道去程至少提前 3 小时到达广州白云 T3
- [ ] 知道返程目标在 13:00 前抵达 KUL T2
- [ ] 确认自己的姓名、护照信息、座位和行李额度
- [ ] 保存自己的登机牌、订单号和航班信息

## 3. 自己必须完成的入境准备

- [ ] 确认自己的护照符合马来西亚入境要求和允许停留时间
- [ ] 按要求完成个人 Malaysia Digital Arrival Card（MDAC）
- [ ] 保存自己的 MDAC 提交成功信息
- [ ] 知道旅行目的、住宿地点、停留时间和返程安排
- [ ] 准备自己可用的支付方式；必要时准备资金证明
- [ ] 知道两家酒店的英文名称和地址

## 4. 手机与电子设备

- [ ] 手机及解锁密码、重要联系人和支付工具可正常使用
- [ ] 手机充电器、充电线和充电宝
- [ ] 马来西亚可用的手机卡、漫游或 eSIM
- [ ] 耳机、相机及相机电池/充电器（如需要）
- [ ] 下载离线地图和必要的翻译工具

## 5. 衣物与个人用品

- [ ] 炎热天气衣物、替换衣物、睡衣、内衣和袜子
- [ ] 适合拍照的服装、鞋子和配饰
- [ ] 轻薄外套、遮阳帽、太阳镜、防晒霜和雨具
- [ ] 个人洗漱用品、护肤品、化妆品和卸妆用品
- [ ] 将护照、手机、钱包、充电宝和药品放入随身包

## 6. 每位旅客出发前最后确认

- [ ] 已查看自己的航班、酒店、接机和返程安排
- [ ] 已和同行者确认集合时间、行李数量和机场碰面位置
- [ ] 已完成个人行李检查
- [ ] 已安排好家中门窗、电源、燃气和宠物/植物

- [x] 已确定：抵达 KUL T2 后完成入境和取行李

- [ ] 确定吉隆坡到马六甲的交通方式、时间、费用和负责人

- [ ] 确认 4 人行李数量适合所选车型

## 5. 行程与活动

- [ ] 确认 Day 1 是否保留 Saloma Link 作为可取消项目
- [ ] 确认 Day 2 吉隆坡街区和马六甲夜市的时间安排
- [ ] 确认 Day 3 马六甲海峡清真寺的出发时间和天气备选
- [ ] 确认景点开放时间、门票和是否需要预约
- [ ] 确认下雨、航班延误或有人疲劳时的取消顺序

## 6. 餐饮与预算

- [ ] 每个重点区域准备 2-3 家餐厅或咖啡馆候选
- [ ] 确认是否有人有忌口、过敏或特别饮食需求
- [ ] 确定共同支出如何记录和结算
- [ ] 预留交通、餐饮、门票、购物和突发情况备用金

## 7. 网络、设备与紧急情况

- [ ] 确认至少 2 人拥有可用网络
- [ ] 确认充电宝、转换插头和公共充电设备
- [ ] 下载离线地图并标记机场、酒店、接机点和重要景点
- [ ] 保存酒店、接机、保险和紧急联系人电话
- [ ] 约定走散后的集合点和联系不上时的处理方式
