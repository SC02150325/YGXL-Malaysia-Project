# 🇲🇾 YGXL 马来西亚项目 / YGXL Malaysia Project

> 4天3晚 · 2026/10/15 - 2026/10/18 · 4人（2男2女）
>
> 广州 → 吉隆坡 → 马六甲 → 吉隆坡机场 → 广州

这是本次旅行的 GitHub 总入口。打开页面后先看每日总计划，再通过详细资料进入餐厅、交通、拍照机位和预算等专题内容。

## 每日总计划

### [Day 1 · 10/15：吉隆坡夜景](./itinerary/README.md#day-1--1015吉隆坡夜景)

抵达、入住、休息和换衣服后，傍晚前往 KLCC、Petronas Twin Towers、Saloma Link，慢慢散步、拍照和吃饭。

### [Day 2 · 10/16：吉隆坡街区 → 马六甲夜市](./itinerary/README.md#day-2--1016吉隆坡街区--马六甲夜市)

上午游览鬼仔巷和茨厂街，下午前往马六甲；傍晚逛荷兰红屋、鸡场街和周五夜市。

### [Day 3 · 10/17：马六甲慢游与海峡日落](./itinerary/README.md#day-3--1017马六甲慢游与海峡日落)

上午慢游历史城区，下午回酒店休息，约 16:30 出发前往马六甲海峡清真寺拍摄日落和蓝调时刻。

### [Day 4 · 10/18：马六甲 → KLIA2 → 广州](./itinerary/README.md#day-4--1018马六甲--klia2--广州)

睡醒、早餐、买伴手礼，约 11:30 离开马六甲前往机场，16:35 飞回广州。

## 使用方式

1. 先看本页的“每日总计划”，了解每天的主线。
2. 点击“详细资料”进入对应分类。
3. 新发现餐厅、拍照点或交通方案时，只更新对应目录，不重写总计划。
4. 每次有意义的调整单独提交 Git，方便比较和回退。

```bash
git add .
git commit -m "补充马六甲餐厅候选"
```

## 旅行原则

不追求打卡数量。睡晚了就少去一个地方，天气不好就切换方案，拍照开心就多停留，累了就回酒店。攻略是参考，不是任务清单。
